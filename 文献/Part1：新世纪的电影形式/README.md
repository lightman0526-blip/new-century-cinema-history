# 第一部分文献索引

这一部分从散文电影与视频论文、手机影像和引擎电影展开，关注它们的创作方法，以及其中的人物、关系与社会经验。

本目录收录四份图书PDF和一份双语文章PDF。下方列出书目、来源和下载入口。
