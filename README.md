# 新世纪电影史

一个从具体作品出发，连接放映、讨论、写作和资料整理的长期研究计划。

我们研究的是2000年以来电影本身的历史：出现了怎样的作品与作者，电影怎样理解、表现和参与它所处的世界，什么延续下来，什么发生了变化。必要时引入更早的作品作为参照。

电影的形式、技术、生产、传播与观看条件都进入研究，但任何一项都不能代替整个电影史。人物、叙事、表演、情感、类型和对社会生活的认识，同样是选片与分析的核心。

这不是“最佳电影榜”，也不追求百科全书式覆盖。问题帮助我们寻找作品，作品也可以推翻原来的分类。

## 当前研究入口

1. 此世代突出的影像创作实践：散文电影与视频论文、手机与网络日常影像、引擎电影。
2. 工业与生产组织：大制片厂、小公司、流媒体平台、独立小组，以及其他资源组织方式。
3. 迷影与大众文化：电影院、粉丝、趣味、“烂片”、梗与评价权。
4. 跨世纪作者：创作中的变化、重复、延续，以及他们与当下的关系。

这些是开放的研究入口，不是固定分类。第一部分已建立初步资料索引，其余部分逐步展开。

## 工作方式

原则上每两至三周一场，以两位组织者可以持续执行为尺度。每场连接导赏、放映、讨论与一篇评论。观众无需完成大量课前观影。

每篇文章至少区分：影片表现了什么；怎样组织和理解这些经验；有哪些可核实的制作、传播与接受条件。讨论中的分歧和未决问题也应留下记录。
