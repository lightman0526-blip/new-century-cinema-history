## 怎样使用

每场主笔选一篇理论或历史文献，另一位组织者读一篇制作访谈。各记一个可用观点、一个影片反例和一个待核实事实。需要长笔记时使用[文献阅读卡](../模板/文献阅读卡.md)。

条目可能需要修订。正文可读、授权下载、再分发、改编和公开放映的条件分别记录，不因网页能打开而默认取得全部权限。
